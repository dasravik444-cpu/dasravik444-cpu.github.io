# Plant Parlour trial page

`plant-parlour/` is the page the trial QR code opens: **Pay with UPI** and an optional **Review us on Google**
button. The bank's own UPI QR is not changed.

- Disconnect the review: replace `plant-parlour/index.html` with the pay-only version (no review button).
- End the trial: remove the QR card; to take the page offline, delete this repository (Settings → Delete).
